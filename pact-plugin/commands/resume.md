# Resume

Use it after a break or a compaction, to see what was in flight before you carry on.

Run `repact resume --no-launch` and show its lines as printed. To resume that session itself, run `repact resume` from a terminal: it prints the same screen, then resumes it in Claude Code. Inside a session it only prints the screen.
