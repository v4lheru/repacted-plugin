# Configuration

Two places hold settings. Options are environment variables, read once per session; set them in the `env` block of your Claude Code `settings.json`. The profile is `${XDG_CONFIG_HOME:-~/.config}/repacted/profile.json`, written by `/repacted:init`; every key is optional.

The list between the markers is generated by `repact-docs-gen`; edit its sources.
